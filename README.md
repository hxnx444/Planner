# My Magical Planner ✦

A free, single-page planner for November–December 2026, designed for GitHub Pages.

## Publish
1. Download and unzip this project.
2. Upload `index.html`, `manifest.webmanifest`, `icon.svg`, and `sw.js` to the root of your existing GitHub repository, replacing the old versions only after keeping a backup.
3. Commit the changes and wait for GitHub Pages to redeploy.
4. Open the site in Chrome on Android, use the browser menu, and choose **Add to Home screen** or **Install app** if available.

## Data & backups
Planner data is saved in the browser's local storage using the existing `magicalPlanner2026_v1` key to preserve compatible existing data. Use Export backup in the app before replacing files or changing devices. Local storage does not sync across devices.

## Included
- Weekly planner, tasks, calendar, study/career, journal, habits and focus timer.
- Daily Salah checklist, workout log, skincare alternating-night plan, money log and little-wins tracker.
- Responsive layout, PWA manifest, icon, offline cache and JSON export/import.
