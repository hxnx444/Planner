# Lock-In Diary (Nov-Dec 2026)

## Put it on the internet (free, 5 minutes)
1. Make a free account at github.com, then New repository, name it `lockin-diary`, set it Public.
2. Click "uploading an existing file", drag in EVERYTHING from this folder (index.html, app.js, styles.css, icons.js, sw.js, manifest.webmanifest, and the fonts and icons folders). Commit.
3. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`, Save.
4. After about a minute your link is https://YOURNAME.github.io/lockin-diary/

## Add to your tablet's home screen (Samsung)
Open the link in Chrome, tap the menu (three dots), choose "Add to Home screen" / "Install app". It then opens full screen and works offline.

## Your data
Everything saves on the device automatically. Open More > Backup to export a file now and then (and to move to a new device with Import). Clearing Chrome's site data erases it, so back up.
If you edit files later, change `lockin-diary-v2` in sw.js to v3 so the app updates.
